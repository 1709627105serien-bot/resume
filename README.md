# 💠 沈立然 · 个人主页 — 昆明学院

✨ 浅蓝色调 · CSS 3D · 玻璃拟态 · 响应式个人网站

## 📋 项目简介

本项目是 **移动应用开发** 课程期末大作业，独立完成以下全流程交付：

- ✅ **个人网站设计** — 6 个独立 Section 板块
- ✅ **代码编写** — 纯原生 HTML + CSS + JavaScript
- ✅ **GitHub 托管** — 完整源码仓库
- ✅ **GitHub Pages 部署** — 公网可访问在线预览

## 🏗 项目结构

```
resume/
├── index.html           # 网站主页（含 6 个独立 Section）
├── project-detail.html  # 子网页（项目详情页）
└── README.md            # 项目说明文档
```

## 🎯 主页结构

| 序号 | Section | 说明 |
|------|---------|------|
| 1 | **顶部导航栏** | 固定导航，滚动高亮，移动端汉堡菜单 |
| 2 | **首页 / Hero** | 个人头像、姓名、简介、快捷按钮 |
| 3 | **关于我** | 个人简介 + 基本信息卡片 |
| 4 | **专业技能** | SVG 环形进度图，滚动触发动画 |
| 5 | **项目经历** | 时间线 + 项目作品卡片网格 |
| 6 | **教育背景** | 学历信息展示 |
| 7 | **联系方式** | 邮箱、地址、学校等联系卡片 |
| 8 | **页面底部 Footer** | 品牌信息 + 导航链接 + 版权 |

## 📄 子网页

- **project-detail.html** — 项目详情页，包含：
  - 面包屑导航
  - 3 个项目的详细介绍（金融数据可视化、医学图像分类、个人网站）
  - 技术栈标签、项目亮点、代码示例、结果展示
  - 返回主页导航

## 🎨 设计亮点

| 特性 | 说明 |
|------|------|
| 🔮 **玻璃拟态** | 全卡片 backdrop-filter 毛玻璃，高光条纹 |

| 🔗 **子页面** | 配套至少一个子网页，面包屑导航 |

## 🚀 部署到 GitHub Pages

### 一键部署

1. GitHub 新建仓库 → 上传所有文件到根目录
2. **Settings → Pages** → Source 选 `main` 分支 → Save
3. 访问 `https://你的用户名.github.io/仓库名/` 即可

### 命令行部署

```bash
cd resume
git init
git add index.html project-detail.html README.md
git commit -m "💠 沈立然 昆明学院 个人网站 - 期末大作业"
git branch -M main
git remote add origin https://github.com/你的用户名/resume.git
git push -u origin main
```
